### 2026-11-11-22-30-28-1c9500 s1 HIGH firstcall/core/read.py:100

(1) LABEL_LINE runs on every email body via _labels(plain) at read.py:272. A single line of 'a' followed by M spaces and no separator costs about M^2/2 steps, because the lazy label and the following [ \t]* both walk the same spaces. Putting N spaces in front makes it about N*M^2, because the two leading [ \t]* around the optional pipe split the indent N ways and each split retries the whole tail. A 40 KB line is on the order of 10^12 steps; the email limit is 10,000,000 bytes (settings.py:28). (2) EMAIL (identity.py:9) is quadratic on a long run of local-part characters with no '@'; it is reached through find_emails on JSON leaves (1 MB limit) and on email bodies in the relay and agent branches, both of which the sender can select from the body. (3) The HTML strip at read.py:207 is quadratic on a body of '<' with no '>'. Harm: the worker is one loop (worker.py:62-71) and CPython's re holds the GIL for the whole match, so the lease-renew thread and the heartbeat stop too. run() holds the job row FOR UPDATE for the duration (jobs.py:112) and reap() uses skip_locked (jobs.py:149), so the job is never reaped while that worker lives; after a restart it is claimed and hangs again, up to max_attempts. One message pins one worker; as many messages as there are workers stops lead processing for every org on the instance, and 60 requests a minute per source is no barrier. Attacker: anyone who can email an org's intake address or submit a form that the provider forwards; source auth does not help because the legitimate provider delivers the content. Basis: traced from the patterns and the call path; not timed, since this session has no execution tool.
Trigger: A stranger emails the org's intake address a text/plain body with one line of ~20,000 spaces, the letter 'a', then ~20,000 more spaces (about 40 KB, far under the 10 MB limit). The provider's webhook delivers it with valid source auth, intake stores it and returns 202, and the worker hangs in LABEL_LINE.finditer inside _labels(). Sending one per worker process stops the queue.
Suggestion: Make each scan linear and bounded. For labels, split the text into lines, skip any line over a few hundred characters, and find the separator with str.partition or a pattern with no adjacent overlapping quantifiers (e.g. strip the line first, then match `\|?[ \t]*([A-Za-z][A-Za-z \-]{0,40}?)[ \t]*(?::|\.{2,}|\|)(.*)` and rstrip ' \t|' from the value in Python). For the HTML strip, use html.parser or `<[^<>]{1,2000}>`.
